Build an isometric explainer of a CI build pipeline: git push, webhook, job queue, runner checkout, dependency cache, compile, unit tests, artifact upload, deploy gate. The vehicle is a commit carrying its real state — changed files, cache hit or miss, test pass/fail counts — and each station narrates the step it just performed. Dependency-free static site, no build step, in a fresh scratch directory outside this repo at ~/scratch/iso-ci-pipeline/.
